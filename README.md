# 📖 DronePilot App e Web App 

Benvenuto nella **DronePilot App**!  
Questa applicazione consente ai piloti di droni di:
- 🗺️ Visualizzare la propria posizione e quella degli altri piloti
- 🚁 Visualizzare e ricevere i droni rilevati tramite OpenDroneID
- 💬 Inviare messaggi diretti tra piloti
- 💬 Chattare in tempo reale in una stanza di gruppo
- 🌦️ Consultare le condizioni meteo e delle costellazioni GNSS aggiornate
- 📍 Inserire e consultare gli spot di volo


## 🛠️ Dettagli Tecnici

- **Sviluppata in Kotlin** per compatibilità Android
- **Firebase Authentication** per il login degli utenti
- **Firestore Database** per la memorizzazione in tempo reale di posizioni e chat
- **Firebase Hosting** per la distribuzione della Web App
- **Google Maps API** per la gestione della mappa
- **OpenWeather API** e **MeteoBlue** per i dati meteo
- **OpenDroneID** per la ricezione delle posizioni e informazioni sui droni tramite Direct Remote ID (DRI)
